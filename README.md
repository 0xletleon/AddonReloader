# Addon Reloader

![screen.png](README/screen.png)

## English

Fast reload Blender add-ons and extensions without restarting. Designed for developers who iterate frequently.

### Features
- One-click reload of add-ons / extensions
- Enable / disable toggle
- Quick open addon folder
- Remembers last selected addon across sessions

### Compatibility
Blender 4.2 LTS and later (up to 5.1+).

### Usage
Install via Blender → Preferences → Extensions. The toolbar appears in the top-right of the top bar.
